# КОНТЕКСТ-ПАК: HARD ROLL Chat, 01.07–05.08.2026

Материал для написания текста трека. Всё построено на сплошном разборе 39 388 сообщений;
каждая цитата проверяема по `msg_id` в `../corpus/messages.jsonl`.

## С чего начинать
1. `10_GENRE_MAP.md` — из какого материала делать какую часть трека + 11 точек переключения эмоции.
2. `11_HOOKS.md` — 54 готовые строки-хука с указанием источника.
3. `05_QUOTES.md` — 442 дословные цитаты по дням.

## Все файлы

| `02_LEXICON.md` | словарь сленга и мемов с частотами и первым употреблением |

| `06_PAIN.md` | депрессивный слой (ТДД/МУККА/pyrokinesis) |

## Ограничения
Голосовые (283) и тексты музыкальных треков не расшифрованы; видео в выгрузке нет.
Подробности — в `../reports/qa.md`.
